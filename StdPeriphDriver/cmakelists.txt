# ---- 宏定义：仅在 Debug / RelWithDebInfo 构建类型下开启 DEBUG ----
# SDK 依赖 DEBUG 宏（CH57x_common.h 的 PRINT(...) printf、CH57x_sys.c 的 _write 串口重定向），
# 用生成器表达式按配置绑定；Release/MinSizeRel 不定义（Release 自带 NDEBUG）。# SDK 库内部的 PRINT(...)（CH57x_usbhostBase.c / CH57x_usbhostClass.c）依赖同一个宏
target_compile_definitions(ch57xstdlib PRIVATE
    $<$<OR:$<CONFIG:Debug>,$<CONFIG:RelWithDebInfo>>:DEBUG=1>
)
